# SHOPKART – E-Commerce Web Application

## Project Description
ShopKart is an e-commerce web application inspired by Amazon and Flipkart. It provides an online shopping platform where users can explore products and interact with an easy-to-use interface.

## Technologies Used
- Java
- JSP & Servlets
- HTML
- CSS
- JavaScript
- MySQL
- Apache Tomcat
- Eclipse IDE
- Maven

## Database
Database Name: `shopkart_db`

## Project Structure
- src/main – Application source code
- pom.xml – Maven dependencies
- .gitignore – Git ignored files
